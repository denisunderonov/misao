

### Метка нового материала и сообщение о сдаче

Карточки дисциплин, тем и домашних заданий содержат только названия. Поле `summary` удалено из модели, генератора и Pages CMS; старые дополнительные поля не попадают в собранный контент.
Чтобы показать ярлык `new`, включите «Метка new» в Pages CMS либо добавьте `isNew: true` во frontmatter материала (для дисциплины — в JSON). При `false` или отсутствии поля метка скрыта.

Отдельный абзац `Отправлять преподавателю не нужно.` (также без точки) автоматически выделяется жирным и контрастным цветом в обеих темах. Дополнительная HTML-разметка не нужна.
