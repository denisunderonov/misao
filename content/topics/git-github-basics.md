## Зачем нужны Git и GitHub

Когда вы меняете программу, полезно сохранять её предыдущие версии: так легче понять, что изменилось, и вернуться к работающему варианту. **Git** помогает вести такую историю на компьютере. **GitHub** — сайт, где можно хранить Git-проекты, делиться ими и совместно проверять код.

Для домашнего задания Git помогает сохранить решение, а GitHub — отправить его преподавателю и запустить проверку. Проект вместе с историей изменений называют **репозиторием**.

## 1. Зарегистрируйтесь на GitHub

1. Откройте [страницу регистрации](https://github.com/signup).
2. Следуйте указаниям: введите адрес электронной почты, придумайте имя пользователя и пароль либо выберите доступный способ входа.
3. Подтвердите почту и пройдите проверку, если GitHub попросит это сделать.
4. Войдите в аккаунт. Для защиты аккаунта рекомендуется включить двухфакторную аутентификацию.

Не отправляйте никому пароль, токены и коды подтверждения. Для сдачи заданий подойдёт бесплатный аккаунт.

## 2. Установите Git

1. Скачайте Git с [официального сайта](https://git-scm.com/downloads) для своей системы и следуйте инструкциям установщика. В Windows для начала можно оставить стандартные настройки.
2. Откройте VS Code и выберите **Terminal → New Terminal**.
3. Введите команду и нажмите Enter:

```bash
git --version
```

Если вы видите номер версии, Git доступен. Если команда не найдена, перезапустите VS Code и проверьте установку. На macOS система может предложить установить инструменты разработчика.

## 3. Настройте имя и почту

При первом использовании укажите данные автора коммитов. Замените примеры на свои значения, сохранив кавычки:

```bash
git config --global user.name "Ваше имя"
git config --global user.email "ваша-почта@example.com"
```

Имя и почта записываются в историю коммитов. При желании вместо личной почты используйте адрес `noreply` из настроек GitHub. Это не вход в аккаунт: пароль здесь не нужен.

## 4. Основные понятия и команды

**Коммит** — сохранённый снимок подготовленных изменений. **Ветка** — отдельная линия работы; в ней удобно выполнять одно задание, не меняя основную ветку проекта.

| Команда | Что делает |
| --- | --- |
| `git clone АДРЕС` | Скачивает репозиторий на компьютер. Вместо `АДРЕС` вставьте ссылку на свою копию. |
| `git status` | Показывает текущую ветку и состояние файлов. |
| `git switch -c homework-1` | Создаёт ветку `homework-1` и переключается на неё. |
| `git add homework1/factorial.py` | Подготавливает конкретный файл к коммиту. |
| `git commit -m "Решение ДЗ"` | Создаёт коммит из подготовленных изменений. |
| `git push` | Отправляет коммиты на GitHub, когда удалённая ветка уже настроена. |
| `git pull` | Получает изменения из связанной удалённой ветки. |
| `git log --oneline` | Показывает краткую историю коммитов. |

Команды проекта выполняйте в терминале **внутри его папки**. Команда `git add` сама не отправляет файл в интернет: после неё нужны коммит и отправка через `git push`.

При первом `push` GitHub может предложить вход через браузер или менеджер учётных данных. Обычный пароль GitHub для Git по HTTPS не используется; подробнее — в [документации GitHub](https://docs.github.com/en/get-started/git-basics/caching-your-github-credentials-in-git).

Для пошаговой сдачи откройте соседнюю карточку **«Сдача домашнего задания»**.
