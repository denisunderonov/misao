**База данных (БД)** — организованный набор взаимосвязанных данных. Например, интернет-магазин хранит сведения о покупателях, товарах и заказах, чтобы быстро находить и обновлять их.

**Система управления базами данных (СУБД)** — программа, с помощью которой создают базу и работают с данными: добавляют, изменяют, удаляют и находят записи. Примеры СУБД: PostgreSQL, MySQL и SQLite.

Представьте библиотеку: база данных похожа на каталог книг, а СУБД — на систему, которая помогает этот каталог вести и искать в нём информацию.

## Что умеет СУБД

- Хранить и находить данные по запросу.
- Обеспечивать совместную работу пользователей и программ.
- Помогать управлять доступом и сохранять целостность данных.
- Предоставлять средства резервного копирования и восстановления; конкретные возможности зависят от СУБД.

Во многих СУБД данные представлены таблицами. **SQL** — язык, который часто используют для работы с реляционными базами данных. Например, приложение магазина может запросить список доступных товаров. SQL — это язык запросов, а СУБД — программа, которая с ними работает.
