> Эта задача взята из собеседования на стажировку в Avito.

В статистике медиана — это значение, которое разделяет верхнюю и нижнюю половины выборки данных. Проще говоря, это «среднее» значение, если выстроить все данные по порядку.

### Задача

Напишите функцию `find_median(input_string)`, которая вычисляет медиану заданного набора чисел.

Медиана вычисляется так:

- если чисел нечётное количество, медиана — это средний элемент после сортировки;
- если чисел чётное количество, медиана — это среднее арифметическое двух средних элементов после сортировки.

### Параметры

- `input_string` — строка, содержащая целые числа, разделённые пробелами. В строке от 1 до 1000 чисел, каждое число в диапазоне от -10^6 до 10^6.

### Возвращаемое значение

Медиана набора чисел. Если результат — целое число, верните целое число; иначе верните число с плавающей точкой, округлённое до 1 знака после запятой.

### Пример

```python
find_median('5 2 9 1 7')
# вернёт 5

find_median('4 1 8 5')
# вернёт 4.5
```

### Объяснение

В первом примере после сортировки список становится [1, 2, 5, 7, 9]. Чисел пять — нечётное количество, поэтому медиана — средний элемент, то есть 5.

Во втором примере после сортировки список становится [1, 4, 5, 8]. Чисел четыре — чётное количество, два средних элемента — 4 и 5, их среднее арифметическое равно 4.5.

## Подсказки

### Подсказка 1

Метод `split()` разбивает строку по пробельным символам и возвращает список строк. Например, `'9 2'.split()` даст `['9', '2']`.

### Подсказка 2

Преобразуйте элементы списка в числа с помощью `int()`, затем отсортируйте их методом `sort()`. Сортировка строк и сортировка чисел могут дать разный порядок.

### Подсказка 3

Используйте `len()` для количества элементов, `% 2` для проверки чётности и `// 2` для поиска середины. Помните, что индексы списка начинаются с нуля.

### Подсказка 4

При нечётном количестве нужен один центральный элемент, при чётном — среднее двух соседних. Проверьте также случай, когда среднее двух чисел целое: условие просит вернуть значение типа `int`.
