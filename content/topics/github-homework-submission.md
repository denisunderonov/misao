Эта инструкция показывает, как сдать ДЗ №1 через GitHub. Если Git ещё не установлен или у вас нет аккаунта, сначала откройте материал **«Git и GitHub: основы»**.

В работе участвуют две копии: **репозиторий преподавателя** с заготовками и **ваш fork** — личная копия на GitHub. Вы меняете файлы в своём fork, затем создаёте **pull request** — запрос, по которому преподаватель увидит ваше решение.

## 1. Создайте свою копию

1. Войдите в GitHub и откройте [репозиторий python-homework](https://github.com/denisunderonov/python-homework).
2. Нажмите **Fork** вверху страницы, выберите свой аккаунт и нажмите **Create fork**.
3. Убедитесь, что в адресе страницы перед `/python-homework` указано **ваше имя пользователя**. Это ваша копия; `denisunderonov/python-homework` — исходный репозиторий преподавателя.

## 2. Скачайте копию на компьютер

1. На странице **своего fork** нажмите **Code → HTTPS** и скопируйте адрес кнопкой копирования.
2. Откройте терминал в VS Code через **Terminal → New Terminal**. Перейдите в папку, где хотите сохранить проект, затем напишите `git clone`, пробел и вставьте скопированный адрес. Пример:

```bash
git clone https://github.com/ВАШ_ЛОГИН/python-homework.git
```

Вместо примера используйте адрес своего fork. Git создаст папку `python-homework`.

3. В VS Code выберите **File → Open Folder** и откройте созданную папку `python-homework`. Откройте новый терминал в ней и проверьте:

```bash
git status
```

Если появляется сообщение, что это не Git-репозиторий, убедитесь, что открыли именно папку проекта, а не папку уровнем выше.

## 3. Создайте ветку

В терминале папки проекта выполните:

```bash
git switch -c homework-1
```

Теперь изменения сохраняются в отдельной ветке `homework-1`. Если такая ветка уже создана, вместо этой команды используйте `git switch homework-1`. Посмотреть текущую ветку можно через `git status`.

## 4. Напишите и проверьте решения

Откройте папку `homework1` и заполните два файла:

- `factorial.py` — функция `factorial(n)`;
- `median.py` — функция `find_median(input_string)`.

Замените `raise NotImplementedError(...)` на своё решение. Сохраните файлы; не переименовывайте их и функции, чтобы тесты смогли их найти.

Чтобы проверить код на компьютере, выполните в терминале **из корня проекта**:

```bash
python -m unittest discover -s tests -v
```

На macOS и Linux может потребоваться `python3` вместо `python`; в Windows — `py`. `OK` означает, что все подготовленные тесты пройдены. Если показана ошибка, прочитайте её, исправьте решение и запустите команду ещё раз. В заготовках тесты намеренно не проходят до написания решений.

## 5. Отправьте файлы в свой fork

Убедитесь, что оба файла сохранены, затем выполните:

```bash
git status
git add homework1/factorial.py homework1/median.py
git commit -m "Решение ДЗ 1"
git push -u origin homework-1
```

`git add` подготавливает файлы, `git commit` сохраняет изменение в истории, `git push` отправляет его **в ваш fork**. Первый раз GitHub может попросить войти через браузер или менеджер учётных данных. Не отправляйте преподавателю пароль или токен. Если видите ошибку авторизации, проверьте, что скопировали адрес своего fork и вошли в нужный аккаунт.

## 6. Создайте pull request преподавателю

1. Откройте свой fork на GitHub. Если появилась кнопка **Compare & pull request**, нажмите её. Иначе откройте **Pull requests → New pull request**; при необходимости выберите **compare across forks**.
2. Проверьте направление: **base repository** — `denisunderonov/python-homework`, его ветка — `main`; **head repository** — ваш fork, ветка — `homework-1`.
3. Укажите понятное название, например «ДЗ №1 — имя студента», и нажмите **Create pull request**. Имя указывайте по правилам, которые сообщил преподаватель: запрос и его содержимое будут публичными.
4. На странице запроса дождитесь проверки. Жёлтый значок означает ожидание или выполнение, зелёная галочка — успешное прохождение, красный крестик — ошибка.

При первом запросе проверка может ожидать разрешения преподавателя. Откройте **Checks** или нажмите **Details**, чтобы прочитать результат. Проверяются обе задачи: пока хотя бы одно решение не готово, общая проверка будет красной.

## 7. Как исправить решение

Оставьте pull request открытым. Исправьте файлы в VS Code и снова выполните:

```bash
git add homework1/factorial.py homework1/median.py
git commit -m "Исправление ДЗ 1"
git push
```

Новые коммиты появятся в том же pull request, проверка запустится снова. Создавать новый запрос для каждого исправления не требуется. Если Git пишет `nothing to commit`, проверьте, сохранили ли вы файл и есть ли новые изменения.

Не изменяйте тесты и настройки проверки для сдачи решения.
