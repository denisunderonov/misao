# МИСАО

Статический сайт учебных материалов на React, TypeScript и Vite. На главной - дисциплины, внутри каждой - «База знаний» и «Домашние задания». База знаний открывает объяснение темы; задание открывает отдельную страницу с полным текстом условий, требованиями и критериями проверки. PDF и вложения не используются.

В начальной версии добавлены **Математика**, **Информатика**, тема **«Линейные уравнения»** и текстовое домашнее задание с пятью уравнениями и текстовой задачей. В информатике оба раздела пока пустые. Каталог дисциплин - сетка по две карточки в строке, новые дисциплины добавляются следующими рядами; на экранах до 760px - одна колонка. В карточках дисциплин только названия, без описаний.

Карточки внутри «Базы знаний» и «Домашних заданий» используют такую же сетку из двух колонок (одна колонка до 760px). В них сохраняются название и краткое описание, расположенные друг под другом.

## Запуск

Нужен Node.js 24 LTS и npm.

```sh
npm ci
npm run dev
```

Откройте адрес из терминала. Перед запуском генерируется проверенный контент. После изменения `content/` во время работы dev-сервера выполните `npm run content` или перезапустите `npm run dev`.

```sh
npm test
npm run build
npx playwright install chromium
npm run test:e2e
```

Браузерные тесты сами собирают production-версию с префиксом `/misao/`, запускают preview и закрывают его после проверки. Готовая статика находится в `dist/`. Для ручного просмотра сборки: `npm run preview`.

## Контент и администрирование

Постоянный бэкенд не нужен. Контент хранится в GitHub, Pages CMS служит отдельной панелью, GitHub Actions проверяет и публикует изменения.

- `content/site.json` - название, описание и настройки сайта.
- `content/subjects.json` - дисциплины и разделы.
- `content/topics/*.md` - объяснения из базы знаний.
- `content/assignments/*.md` - полные условия домашних заданий в Markdown.
- `.pages.yml` - конфигурация Pages CMS.
- `scripts/content.mjs` - проверка идентификаторов, связей, дат и непустого текста материалов.
- `src/generated/content.json` - результат генерации; не редактируется вручную.

Pages CMS заявляет бесплатность и онлайн-версии, и исходного кода: [официальные условия](https://pagescms.org/#is-pages-cms-free). Инструкция по подключению и повседневной работе: [docs/ADMINISTRATION.md](ADMINISTRATION.md).

## Публикация на GitHub Pages

1. Репозиторий уже задан как `https://github.com/denisunderonov/misao`. Сохраните и отправьте проверенные исходники вместе с `package-lock.json` в `main`.
2. В репозитории откройте **Settings → Pages → Build and deployment → Source → GitHub Actions**.
3. Запушьте изменения в `main` или вручную запустите workflow **Check and deploy to GitHub Pages**.
4. Дождитесь успешных jobs `check`, `build`, `deploy`. Адрес появится в окружении `github-pages`.
5. Подключите этот репозиторий к Pages CMS по инструкции ниже.

Workflow автоматически получает URL-префикс из GitHub Pages. Поэтому работает и проектный адрес `https://<user>.github.io/<repo>/`, и корневой `https://<user>.github.io/`. Маршруты вида `#/subjects/mathematics` не требуют серверных перенаправлений.

Для ручной сборки с префиксом:

```sh
VITE_BASE_PATH=/misao/ npm run build
```

Публикация подготовлена, но push/deploy и реальный вход в Pages CMS в рамках подготовки не выполнялись. Секреты или токены в исходники добавлять не нужно. Перед публикацией проверьте HTTPS, доступ Pages CMS и лицензии шрифтов: [docs/SECURITY.md](SECURITY.md).

Production HTML ограничивает выполнение кода через CSP; Markdown разбирается без исполняемых frontmatter-движков. Workflow проверяет секреты в Git и артефакте, зависимости, контент и пользовательские сценарии. Шаги Actions закреплены SHA и работают с минимальными правами; для публикации используется штатный GITHUB_TOKEN/OIDC, без личного токена.

## Команда и проверки

Роли главного агента, разработчика, дизайнера и тестировщика описаны в [AGENTS.md](../AGENTS.md). Сценарии и результаты проверки находятся в [docs/TESTING.md](TESTING.md).

Дизайн следует [сайту-референсу](https://slavaver.github.io/web-course-site/): индиговый фон с абстрактной SVG-волной, крупные заголовки NextArt, основной текст Gilroy и широкие цветные карточки. Шрифты подключены локально; их происхождение и сведения о лицензировании находятся в [public/fonts/README.md](../public/fonts/README.md). Фоновый SVG нарисован для этого проекта.

Переключатель солнце/луна меняет светлую и тёмную темы. Выбор сохраняется в браузере (`misao-theme`) и применяется до загрузки приложения; без сохранённого выбора используется системная тема. Запрет localStorage не мешает работе сайта и переключению темы.

В шапке - кликабельный совёнок, ведущий на главную. На широких экранах «Дисциплины» выровнены по центру, кнопка темы находится справа. На экранах шириной 760px и меньше ссылка и смена темы доступны внутри бургер-меню. Меню закрывается по Escape, клику снаружи, переходу по ссылке и при переключении на desktop. Источник и лицензия логотипа: [docs/ASSETS.md](ASSETS.md).

Футер по центру: «Дизайн и разработка сайта: Github», где Github ведёт на профиль из `site.githubUrl`; под ним отдельной строкой «© 2026».

Вёрстка проверяется на ширинах 320, 375, 768, 1024, 1440 и 1920 пикселей в обоих цветовых режимах. Широкие таблицы и блоки кода прокручиваются внутри статьи, не растягивая страницу.

## Если позже понадобится бэкенд

Для текущего каталога статических материалов достаточно файлов и Pages CMS. Если появятся аккаунты студентов, отправка работ и оценки, можно подключить **Django + Django Admin** на отдельном сервере. **FastAPI** подходит для собственного API, но административный интерфейс потребуется добавить отдельно. GitHub Pages продолжит размещать клиентскую часть; серверный Python-код на нём не выполняется.
