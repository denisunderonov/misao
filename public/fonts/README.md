# Шрифты референса

По запросу владельца сайта используются те же семейства, что и в референсе:

- Gilroy Regular / Medium - основной текст.
- NEXT ART Regular / SemiBold / Bold - заголовки.

Источник файлов: https://github.com/slavaver/web-course-site/tree/main/public/assets/fonts

Пути в исходном репозитории:

- `public/assets/fonts/gilroy/Gilroy-Regular.ttf`
- `public/assets/fonts/gilroy/Gilroy-Medium.ttf`
- `public/assets/fonts/nextart/NEXTART_Regular.otf`
- `public/assets/fonts/nextart/NEXTART_SemiBold.otf`
- `public/assets/fonts/nextart/NEXTART_Bold.otf`

Получены 18 ноября 2026 года. Проверенный на этот момент коммит репозитория: `3be69aeaa6446b9f5bae0603b4280af1d55ef26c`.
Файлы сохранены без модификации. Уведомления об авторстве внутри файлов сохранены.
Публичная доступность исходного репозитория не подтверждает наличие лицензии на распространение шрифтов: отдельный лицензионный документ в дереве исходного репозитория не найден. Настоящий файл фиксирует происхождение и не предоставляет лицензию на шрифты.
