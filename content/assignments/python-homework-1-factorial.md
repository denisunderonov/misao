> Эта задача взята из собеседования на стажировку Аналитика Данных в X5.

Факториал числа n (обозначается как n!) — это произведение всех положительных целых чисел от 1 до n включительно. Например:

- 5! = 5 × 4 × 3 × 2 × 1 = 120
- 3! = 3 × 2 × 1 = 6
- 1! = 1
- 0! = 1 (по определению)

### Задача

Напишите функцию `factorial(n)`, которая возвращает факториал числа n. Если число отрицательное, функция должна вернуть -1: для отрицательных чисел факториал не определён.

### Параметры

- n — целое число в диапазоне от -100 до 100. Для корректных входных данных факториал не превысит 10^9.

### Возвращаемое значение

Целое число — факториал n, либо -1, если n отрицательное.

### Пример

```python
factorial(5)
# вернёт 120

factorial(0)
# вернёт 1

factorial(-5)
# вернёт -1
```

### Объяснение

5! = 5 × 4 × 3 × 2 × 1 = 120. Факториал нуля равен 1 по определению. Отрицательные числа не имеют факториала, поэтому для них возвращаем -1.

## Подсказки

Сначала проверьте особый случай: что функция должна вернуть для отрицательного числа? Используйте условие `if` и `return`.

Для произведения понадобится переменная-накопитель. Какое начальное значение не изменяет число при умножении? Оно также поможет получить правильный ответ для нуля.

### Подсказка 4
