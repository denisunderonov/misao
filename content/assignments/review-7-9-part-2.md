## 1. Рациональные уравнения

Решите уравнения. Перед решением укажите значения переменной, при которых выражения имеют смысл. Проверьте полученные корни.

1. $\dfrac{6}{x} = 3$
2. $\dfrac{x + 2}{x - 1} = 2$
3. $\dfrac{2}{x - 3} + 1 = \dfrac{5}{x - 3}$

## 2. Неравенства

Решите неравенства и запишите ответы в виде числовых промежутков.

1. $3x - 5 > 7$
2. $2(x + 1) \leq 10$
3. $5 - 2x < 11$

## 3. Функции

**Задание 1.** Дана функция $y = 2x - 3$. Найдите значение функции при $x = -1$, $x = 0$ и $x = 4$.

**Задание 2.** Дана функция $y = 3x + 1$. Определите, какие из точек принадлежат её графику. Для каждой точки покажите проверку.

- $A(0; 1)$;
- $B(2; 6)$;
- $C(-1; -2)$.

**Задание 3.** Постройте график функции $y = -x + 2$. Для этого заполните таблицу, отметьте полученные точки на координатной плоскости и проведите через них прямую.

| $x$ | $-1$ | $0$ | $2$ | $3$ |
|---|---:|---:|---:|---:|
| $y$ |  |  |  |  |

По построенному графику определите:

1. Значение $y$ при $x = 1$.
2. Значение $x$, при котором $y = 0$.

Отправлять преподавателю не нужно.

## Ответы для самопроверки

**Рациональные уравнения**

1. $x = 2$; ограничение $x \ne 0$.
2. $x = 4$; ограничение $x \ne 1$.
3. $x = 6$; ограничение $x \ne 3$.

**Неравенства**

1. $x > 4$, то есть $(4; +\infty)$.
2. $x \leq 4$, то есть $(-\infty; 4]$.
3. $x > -3$, то есть $(-3; +\infty)$.

**Функции**

1. При $x = -1$: $y = -5$; при $x = 0$: $y = -3$; при $x = 4$: $y = 5$.
2. Точки $A$ и $C$ принадлежат графику: $3\cdot 0 + 1 = 1$, $3\cdot(-1) + 1 = -2$. Точка $B$ не принадлежит: при $x = 2$ получаем $y = 7$, а не $6$.
3. Значения $y$ в таблице: $3$, $2$, $0$, $-1$. При $x = 1$ получаем $y = 1$; при $y = 0$ получаем $x = 2$.
