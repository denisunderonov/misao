# Работа над МИСАО

Статический сайт учебных материалов: React, TypeScript, Vite, GitHub Pages.
Веб-сервер приложения и база данных не нужны. Контент редактирует владелец через Pages CMS.

## Команда агентов

- Главный агент: требования, архитектура, контент, CMS, CI и итоговая проверка.
- Разработчик: компоненты, навигация, Markdown, адаптивность.
- Дизайнер: визуальная система и проверка desktop/mobile по реальным скриншотам.
- Тестировщик: сценарии, автоматические проверки и отчет о результатах.

Роли могут обмениваться замечаниями и вносить исправления. Перед изменением чужого участка согласуйте границу работы. Одна установка зависимостей на команду.

## Правила

- Маршруты используют hash, чтобы прямые ссылки работали на GitHub Pages.
- Все публичные пути учитывают Vite BASE_URL, включая изображения Markdown и логотип.
- Источники: content/site.json, content/subjects.json, content/topics/*.md (база знаний), content/assignments/*.md (домашние задания).
- Домашние задания публикуются целиком в Markdown на странице сайта. PDF, вложения и кнопки скачивания не используются.
- src/generated/content.json генерируется; не редактировать вручную.
- Не добавлять токены GitHub, пароли и OAuth-секреты в клиентское приложение.
- Не добавлять разделы, аккаунты, прием работ или оценки без запроса пользователя.
- Интерфейс - только библиотека дисциплин, базы знаний и домашних заданий. Без промоблоков, слоганов, хлебных крошек, дат, времени чтения и дублирующих подсказок. Пользователь отдельно запросил фоновый абстрактный SVG и переключатель тёмной/светлой темы.
- В шапке только кликабельный логотип-совёнок со ссылкой на главную. На desktop «Дисциплины» по центру, переключатель темы справа. При ширине 760px и меньше навигация и переключатель скрыты в бургер-меню; сохранять доступность с клавиатуры и корректный фокус при закрытии и изменении размера.
- Футер по центру: «Дизайн и разработка сайта: Github» (Github ведёт на профиль владельца), следующая строка «© 2026».
- Каталог дисциплин: сетка из двух колонок на широких экранах; новые карточки добавляются следующими рядами по две. При ширине 760px и меньше - одна колонка. На карточках дисциплин только названия, описания дисциплин не используются в контенте и CMS. Карточки материалов также содержат только заголовки; поле summary не поддерживается.
- Внутри «Базы знаний» и «Домашних заданий» такая же сетка: две колонки на широких экранах и одна при ширине 760px и меньше. В карточках материалов отображается только название; новые материалы занимают следующие ряды.
- Объяснения из базы знаний и полные условия домашних заданий - независимые Markdown-записи; весь текст отображается на соответствующей странице.
- Заголовки: NextArt; основной текст: Gilroy из референса, подключены локально. Тема сохраняется в localStorage misao-theme и применяется до первого рендера. Проверять оба цветовых режима и ширины от 320 до 1920px.
- Дизайн следует референсу slavaver.github.io/web-course-site: почти чёрный индиговый фон, широкие цветные карточки, крупные заголовки. Основной текст 20px desktop и минимум 18px mobile.
- Перед завершением выполнить npm test, npm run build, npm run test:e2e и проверить внешний вид.
- Изменения контента должны проходить build-time валидацию. Не ослаблять тесты ради успешного прогона.
- Публикация целится в GitHub Pages. Не регистрировать другой хостинг без запроса.
