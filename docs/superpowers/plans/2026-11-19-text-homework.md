# Текстовые домашние задания

**Запрос:** все условия ДЗ публикуются непосредственно на сайте; PDF больше не используется.

**Решение:** сохранить маршруты, сетки карточек, Markdown-редактор Pages CMS и существующий дизайн. Страница задания содержит заголовок и полный Markdown-текст. Теория и ДЗ остаются отдельными коллекциями.

- [x] Сначала обновить тесты нового контракта и подтвердить падение на старой реализации.
- [x] Убрать PDF из TypeScript, валидатора, интерфейса и CMS. Сохранить YAML-only parsing, проверку ссылок на дисциплины/разделы, дат, уникальности и непустого текста.
- [x] Перенести пять уравнений и текстовую задачу из демонстрационного PDF в Markdown, удалить сам PDF и его генератор.
- [x] Обновить текущие инструкции администратора/README/AGENTS/security и добавить актуальные результаты проверки, не переписывая исторические отчёты.
- [x] Выполнить npm test, npm run build, npm run test:e2e; проверить актуальные desktop/mobile снимки и отсутствие PDF в dist.

Зависимости и настройки защиты production не меняются. Публикация и push не входят в запрос.

Результат: сначала 6 ожидаемых падений, затем 63 Vitest + build + 156 Playwright прошли. В dist PDF отсутствуют. Desktop/mobile проверены по реальным снимкам; независимый review без замечаний к переходу на текстовый формат.
