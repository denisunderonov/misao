Условие позволяет программе выбирать действие. Конструкция `if` выполняет блок, когда условие истинно; `elif` проверяет следующий вариант, а `else` выполняется, если предыдущие условия ложны.

```python
score = 72
if score >= 80:
    print("Отлично")
elif score >= 60:
    print("Зачёт")
else:
    print("Нужно повторить")
# Зачёт
```

После условия ставится двоеточие, а команды внутри блока записываются с отступом — обычно четыре пробела. Сравнения `==`, `!=`, `>`, `<`, `>=`, `<=` дают `True` или `False`. Не путайте сравнение `==` с присваиванием `=`.

Условия можно объединять: `and` требует выполнения обоих условий, `or` — хотя бы одного, а `not` меняет результат на противоположный.

```python
age = 19
has_ticket = True
if age >= 18 and has_ticket:
    print("Вход разрешён")
```
