Чтобы писать и запускать программы, нужны три компонента: **Python** выполняет код, **Visual Studio Code** — редактор, а расширение **Python** добавляет в редактор поддержку языка.

## 1. Установите Python

1. Откройте [страницу загрузки Python](https://www.python.org/downloads/) и скачайте установщик Python 3 для своей системы.
2. Запустите скачанный файл и следуйте инструкциям установщика. В Windows, если установщик предлагает добавить Python в `PATH`, включите эту настройку: она поможет запускать Python из терминала.
3. Проверьте установку: откройте «Терминал» на macOS или PowerShell на Windows и выполните команду:

```text
python --version
```

Если команда не сработала, попробуйте `python3 --version` на macOS или `py --version` на Windows. В ответ должна появиться версия Python 3, например `Python 3.x.x`. Если команда не найдена, закройте и снова откройте терминал; при необходимости проверьте установку и настройки пути.

## 2. Установите VS Code и расширение

1. Скачайте [Visual Studio Code](https://code.visualstudio.com/) и установите программу.
2. Откройте VS Code. Нажмите значок **Extensions** в левой панели или используйте `Ctrl+Shift+X` на Windows и `Cmd+Shift+X` на macOS.
3. Найдите расширение **Python** от **Microsoft** и нажмите **Install**. Расширение не заменяет установленный интерпретатор Python.

## 3. Создайте и запустите программу

1. Через **File → Open Folder** откройте или создайте папку для занятий.
2. Создайте в ней файл `hello.py` и напишите:

```python
name = "Студент"
print(f"Привет, {name}!")
```

3. Сохраните файл: `Ctrl+S` на Windows или `Cmd+S` на macOS.
4. Откройте палитру команд: `Ctrl+Shift+P` на Windows или `Cmd+Shift+P` на macOS. Выберите **Python: Select Interpreter**, затем установленный Python 3.
5. Нажмите кнопку **Run Python File** ▶ в правом верхнем углу редактора. В терминале внизу появится:

```text
Привет, Студент!
```

Измените имя, сохраните файл и запустите его ещё раз. Подробнее и со скриншотами можно посмотреть в [официальной инструкции VS Code](https://code.visualstudio.com/docs/python/python-tutorial).

## Если программа не запускается

- Проверьте расширение файла: должно быть `.py`, а не `.txt`.
- Убедитесь, что Python установлен отдельно и выбран через **Python: Select Interpreter**.
- Прочитайте сообщение в терминале: в нём обычно указаны строка и причина ошибки. Проверьте кавычки, скобки и отступы.
- Если редактор не видит Python после установки, перезапустите VS Code и выберите интерпретатор снова.
