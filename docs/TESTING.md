# Проверка МИСАО

Сайт проверяется на собранной production-версии с базовым адресом `/misao/` — так же, как в репозитории GitHub Pages. Маршруты после `#` позволяют открывать и обновлять ссылку на конкретную тему без серверного роутера.

## Команды

```sh
npm ci
npm test
npx playwright install chromium
npm run test:e2e
```

`test:e2e` автоматически собирает сайт и запускает preview на `127.0.0.1:4173`. Порт должен быть свободен. Chromium проверяет ширины **320, 375, 768, 1024, 1440 и 1920 px**, каждую в светлой и тёмной теме. На 320 и 375 px дополнительно включены мобильный режим и сенсорный ввод. Всего 12 конфигураций браузера. При падении сохраняется trace в `test-results/`; его можно открыть командой `npx playwright show-trace <путь-к-trace.zip>`.

Браузерные тесты используют актуальные дисциплины, первую опубликованную статью базы знаний и первое домашнее задание из репозитория. Добавление, переименование или удаление материалов через CMS не требует менять тесты. При отсутствии определённого типа материалов пропускаются только зависимые от него сценарии, с пояснением причины. Независимые компонентные тесты продолжают проверять оба типа материалов и пустые состояния на тестовых данных. Проверка переполнения обходит все страницы контента и страницу ошибки. Снимки этих страниц для всех размеров и тем сохраняются в `tmp/qa/`.

## Автоматические сценарии

| Проверка | Ожидаемый результат |
| --- | --- |
| Главная → дисциплина → База знаний → статья | Отображается объяснение; ссылки скачивания домашнего задания нет. |
| Дисциплина → Домашние задания → задание | Отображаются отдельный Markdown-текст задания и ссылка скачивания PDF. |
| Скачать задание | Браузер скачивает файл `.pdf`; ответ успешен, MIME `application/pdf`, файл начинается с `%PDF-`. |
| Прямая ссылка и обновление страницы | Статья открывается на `/misao/#/subjects/:id/topics/:slug`, ДЗ — на `/misao/#/subjects/:id/homework/:slug`. |
| Возврат в дисциплину и кнопка браузера «Назад» | Переходы сохраняют рабочую историю навигации. |
| Дисциплина без материалов | В базе знаний и домашних заданиях отображаются отдельные пустые состояния без чужих материалов. |
| Неизвестная дисциплина, статья, ДЗ и маршрут | Отображается страница «Не найдено» и ссылка на дисциплины. |
| Все страницы в 12 конфигурациях браузера | URL и заголовок соответствуют странице, нет горизонтального переполнения, Tab переводит фокус на ссылку. Снимок делается до действий с клавиатурой. |
| NextArt и Gilroy | Все 5 начертаний загружаются как реальные font-face; ошибок загрузки шрифтов нет, заголовки и текст используют нужные семейства. |
| Переключатель темы | Меняет светлую/тёмную тему, сохраняет выбор и восстанавливает его после перезагрузки. |
| Запрет localStorage | Сайт и переключение темы работают; после перезагрузки применяется системная тема. |
| Footer | Ссылка «мой github» ведёт на GitHub-профиль из настроек сайта. |
| Некорректные идентификаторы и ссылки в контенте | Сборка останавливается до публикации. |
| Черновики статьи и ДЗ | Материалы с `published: false` не публикуются, в том числе незаполненные черновики. |
| Одинаковый slug статьи и ДЗ | Разрешён: разные типы имеют независимые адреса; дубликаты внутри одного типа запрещены. |
| Удаление последней записи коллекции | Отсутствующий каталог Markdown преобразуется в пустой массив материалов. |
| Отсутствующий, подменённый или небезопасно указанный PDF | Сборка останавливается с ошибкой. |
| Пустой текст или неверная дата | Сборка останавливается с ошибкой. |
| Markdown с таблицей, HTML и небезопасной ссылкой | Таблица и выделение отображаются; HTML-скрипт и javascript-ссылка не исполняются. |
| Ссылка пропуска навигации | После активации клавиатурой фокус переходит в основное содержимое. |
| Схема Pages CMS | База знаний и ДЗ хранятся в разных Markdown-коллекциях; поле PDF присутствует только у ДЗ. |

## Ручная приёмка после подключения Pages CMS

Эти проверки требуют учётной записи GitHub и прав на репозиторий. Локальные тесты не подтверждают авторизацию внешнего сервиса.

1. Войти в Pages CMS через GitHub, открыть нужные репозиторий и ветку. Проверить настройки сайта, дисциплины и отдельные коллекции «База знаний» и «Домашние задания».
2. Создать черновик статьи базы знаний без PDF; отдельно создать черновик ДЗ, заполнить его текст и прикрепить PDF. Проверить успешную сборку и отсутствие обоих черновиков на сайте.
3. Опубликовать оба материала. После успешного GitHub Actions открыть их прямые ссылки: у статьи нет скачивания, у ДЗ скачивается PDF.
4. Исправить объяснение статьи, текст ДЗ и заменить PDF. После следующей сборки проверить обновление текста и файла в соответствующих разделах.
5. Создать ошибочную ссылку на раздел или отсутствующий PDF. Проверить отказ проверки контента: опубликованная ранее версия должна оставаться доступной.
6. Удалить тестовые материалы и ненужный PDF, включая последнюю запись коллекции. Проверить навигацию и два пустых состояния дисциплины.
7. Проверить доступ к редактированию у единственного владельца репозитория и отсутствие возможности редактирования у студента без этих прав.

## Результаты проверки 18 ноября 2026

После разделения базы знаний и домашних заданий и добавления переключения темы:

- `npm test`: **48 тестов прошли** — валидация и загрузка контента, две коллекции CMS, Markdown, независимые страницы статьи и ДЗ, footer, клавиатура и тема при доступном и заблокированном хранилище.
- `npm run build`: production-сборка завершилась успешно.
- `npm run test:e2e`: **120 тестов прошли** за 1,3 минуты — 10 сценариев в каждой из 12 конфигураций размера и темы. PDF, прямые ссылки, настоящая перезагрузка, локальные шрифты и сохранение темы проверяются на production-сборке с `/misao/`.
- После визуального ревью уточнён сценарий снимков: URL и заголовок проверяются перед снимком, Enter по ссылке возврата больше не меняет страницу перед сохранением изображения. **Повторный прогон всех 12 адаптивных сценариев прошёл за 23,8 секунды**, снимки в `tmp/qa/` обновлены.
- Через CUA визуально проверены главная в светлой и тёмной теме и страница дисциплины. Локальный сервер `http://localhost:5173/` возвращает HTTP 200.

Окружение: Node.js 24.11.0, npm 11.6.1, Vite 8.3.8, Vitest 5.1.1, Chromium 159.

Проверка загрузки шрифтов подтверждает наличие и использование файлов, а не права на их распространение. Файлы взяты из указанного референса; отдельная лицензия не обнаружена. Подробности и источники перечислены в [public/fonts/README.md](../public/fonts/README.md).

При предыдущей проверке этого же набора зависимостей `npm audit --omit=dev` сообщил **0 уязвимостей**, полный `npm audit` — **6 high** в цепочке инструментов разработки из-за `picomatch` (через `fdir`, `tinyglobby`, Vite, Vitest и `plugin-react`). С тех пор зависимости не менялись; в финальный прогон аудит повторно не выполнялся. На момент той проверки исправленная версия для [GHSA-fc5q-39xc-vjpf](https://github.com/advisories/GHSA-fc5q-39xc-vjpf) не была опубликована. Проект не принимает glob-шаблоны от посетителей. Эта известная проблема не представляется как исправленная.

Авторизация и сохранение материалов через внешний Pages CMS, ручные сценарии выше и фактическая публикация на GitHub Pages **не проверены**: для них требуется подключить репозиторий и учётную запись владельца.
